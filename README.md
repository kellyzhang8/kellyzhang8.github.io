# Kaili (Kelly) Zhang Academic Homepage

Personal academic homepage for Kaili (Kelly) Zhang, Ph.D. student in Urban and Regional Science at Texas A&M University.

Live site: https://kellyzhang8.github.io/

## Structure

- `index.html`: single-page homepage content and SEO metadata.
- `assets/css/main.css`: site styling.
- `assets/img/`: profile photo, TAMU logo, favicon, and publication figures.
- `assets/files/`: CV and publication PDFs.
- `robots.txt` and `sitemap.xml`: search indexing helpers.

Old Jekyll template files and legacy carbon/webmap data were removed from the live homepage branch to keep the repository focused on the academic website.
